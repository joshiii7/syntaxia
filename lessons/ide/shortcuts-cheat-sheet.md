# IDE Shortcuts Cheat Sheet

This page is a reference, not a lesson to work through top to bottom. It collects every shortcut mentioned across this section, from [Basic IDE Navigation & Features](/lessons/ide/ide-navigation-and-features) through [Extensions & Customization](/lessons/ide/extensions-and-customization), plus a few more genuinely common ones, all in one place to come back to later. Shortcuts are shown as Windows/Linux, then Mac.

## Editing

| Action | Windows / Linux | Mac |
|---|---|---|
| Save | `Ctrl+S` | `Cmd+S` |
| Find in current file | `Ctrl+F` | `Cmd+F` |
| Find and replace | `Ctrl+H` | `Cmd+H` |
| Search across all files | `Ctrl+Shift+F` | `Cmd+Shift+F` |
| Toggle line comment | `Ctrl+/` | `Cmd+/` |
| Add a cursor above/below (multi-cursor) | `Ctrl+Alt+Up/Down` | `Cmd+Option+Up/Down` |

## Navigation & window

| Action | Windows / Linux | Mac |
|---|---|---|
| Command palette | `Ctrl+Shift+P` | `Cmd+Shift+P` |
| Quick-open a file by name | `Ctrl+P` | `Cmd+P` |
| Toggle the integrated terminal | `` Ctrl+` `` | `` Cmd+` `` |
| Toggle the file explorer sidebar | `Ctrl+B` | `Cmd+B` |
| Split the editor | `Ctrl+\` | `Cmd+\` |
| Open the Extensions panel | `Ctrl+Shift+X` | `Cmd+Shift+X` |
| Pick a color theme | `Ctrl+K Ctrl+T` | `Cmd+K Cmd+T` |

## Running & debugging

| Action | Windows / Linux | Mac |
|---|---|---|
| Start/continue debugging | `F5` | `F5` |
| Step over (during a paused debug session) | `F10` | `F10` |
| Step into (during a paused debug session) | `F11` | `F11` |
| Stop debugging | `Shift+F5` | `Shift+F5` |

## A tip for remembering these

Nobody memorizes a list like this by reading it once. The realistic path is to keep this page bookmarked, and reach for the command palette (`Ctrl+Shift+P` / `Cmd+Shift+P`) whenever you forget one. Typing what you want to do (for example "split editor") shows you the shortcut right next to the command, which tends to make it stick after a few real uses.
